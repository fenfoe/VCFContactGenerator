# VCFContactGenerator
PhoneNumberGenerator is a tool designed to generate all possible phone numbers based on a given pattern, where placeholders ('X') in the number can be replaced with digits from 0 to 9. After generating the phone numbers in vCard format, they can be imported into a phone emulator or messaging apps like WhatsApp and Telegram. By sending the contacts to these apps, investigators can search for associated profile photos, status messages, and even group memberships of the person in question. This can provide valuable visual identification and further context about the individual or organization.
