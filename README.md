# VCFContactGenerator
PhoneNumberGenerator is a tool designed to generate all possible phone numbers based on a given pattern, where placeholders ('X') in the number can be replaced with digits from 0 to 9. After generating the phone numbers in vCard format, they can be imported into a phone emulator or messaging apps like WhatsApp and Telegram.

git clone https://github.com/fenfoe/VCFContactGenerator.git
cd VCFContactGenerator
